# Research Report

**Question:** What are the main approaches to building multi-agent LLM systems?

## Introduction
The development of multi-agent Large Language Model (LLM) systems is a rapidly evolving field, with various approaches being explored to enable effective collaboration and communication among autonomous agents. This report aims to provide an overview of the main approaches to building multi-agent LLM systems, including existing architectures and communication protocols [1, 2, 3, 4, 5, 6, 7, 8, 9].

## Main Findings
The key findings indicate that existing architectures for multi-agent systems include monolithic, modular, multi-agent, embodied, and tool-augmented systems, with a focus on scalability, flexibility, and interoperability [1, 2, 3, 4, 5]. Additionally, orchestrated multi-agent systems and unified architectural frameworks have been proposed to formalize the technical composition of multi-agent systems [1, 2, 3]. In terms of communication protocols, standardized frameworks such as Model Context Protocol (MCP), Agent-to-Agent (A2A) protocol, and Agent Network Protocol (ANP) have emerged to establish structured, interoperable communication for tool interaction and peer specialized agentic collaboration [6, 2, 7, 8, 9].

## Comparison
The following table summarizes the main architectures and communication protocols for multi-agent LLM systems:
| Architecture/Protocol | Description | Reference |
| --- | --- | --- |
| Monolithic | Centralized architecture | [1] |
| Modular | Decentralized architecture | [2] |
| Multi-agent | Autonomous agents collaborating through coordination and communication | [3] |
| MCP | Standardized communication framework for tool interaction | [6] |
| A2A | Protocol for agent-to-agent communication | [7] |
| ANP | Protocol for agent network communication | [8] |

## Conclusion
In conclusion, the development of multi-agent LLM systems requires a comprehensive understanding of existing architectures and communication protocols. The findings suggest that a unified architectural framework and standardized communication protocols are essential for enabling effective collaboration and communication among autonomous agents [1, 2, 3, 4, 5, 6, 7, 8, 9]. Further research is needed to explore the applications and implications of these approaches in real-world scenarios.
